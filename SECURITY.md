# Security

Please report security problems privately, through GitHub's
[security advisories](https://github.com/larsx2/raiden/security/advisories/new), never in a public
issue or pull request.

Say what the problem is, how to reproduce it, and what someone could do with it. You'll get an
answer within a week. Once a fix is out, the advisory is published and credits you, unless you'd
rather it didn't.

Raiden is experimental and built from source, so fixes go to `main` only. Update to the latest
`main` to get them.
